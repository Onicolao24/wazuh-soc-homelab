# Wazuh SOC Home Lab

## Overview

This project documents the creation of a hands-on Security Operations Center (SOC) home lab using Wazuh SIEM, Ubuntu Server, and Kali Linux.

The purpose of this lab is to practice deploying a SIEM, monitoring endpoints, generating security events, investigating alerts, and documenting the SOC analysis process.

## Lab Objectives

- Deploy Wazuh SIEM on Ubuntu Server
- Connect a Kali Linux endpoint using the Wazuh Agent
- Monitor security events and system logs
- Detect failed authentication attempts
- Monitor file integrity changes
- Investigate alerts using the Wazuh Dashboard
- Map selected events to MITRE ATT&CK
- Document the complete SOC workflow

## Technologies
